Right now this is a single file with nothing beside it, so an image has to come from a web address:

Swap the placeholder for <img src="https://..." alt="Describe the image">. The alt text isn't optional — it's what a screen reader announces, and what shows if the image fails to load.

Once we publish

When this becomes a real repo, images live in an assets/img/ folder and the path shortens to assets/img/filename.jpg. Send me the files at that point and I'll wire them in.

Photos straight off a phone are often 4–8 MB, which makes a page crawl. I'll resize anything you send before it goes live.

Editing this template

Everything you need to change is near the top of the file or inside a labelled block.

Add a tab

Copy any <section class="tab"> block, give it a fresh id and a new data-label. The nav bar reads the sections and rebuilds itself, so there's no second place to update.

Remove or reorder a tab

Delete the section, or move it up or down among the others. Nav order follows the order of the sections in the file.

Change the theme

The swatches in the header are for previewing only — they don't save. Once you've settled on one, set it permanently by editing data-theme on the <html> tag at the top of the file.

The four themes are just variable sets in the stylesheet. If none of them fit, tell me the mood you're after and I'll build one.

Blocks you can reuse

  • .grid with .card children — parallel items
  • .note — callouts
  • figure — images with captions
  • blockquote, table, hr — standard
  • .eyebrow — the small label above a heading
  • .lead — the larger intro paragraph
